# Privacy Policy for Beluga Shorts & Cinema X-Ray

Last updated: October 25, 2026

## Overview
This application is a personal automation tool used exclusively by the channel owner to manage, render, and publish video content to YouTube via the YouTube Data API v3.

## Data Collection & Usage
- **Google User Data:** The application only accesses data necessary to upload videos and manage video comments on the authenticated channel.
- **Data Storage:** OAuth tokens and credentials are encrypted and stored locally or within secure GitHub repository secrets. No user data is shared, sold, or transferred to any third party.
- **Third-Party Services:** Content generation utilizes official Google Gemini APIs and YouTube Data API v3 in strict compliance with Google API Services User Data Policy.
